# Módulo: Orientación al Cliente — CLI (1 dimensión, 4 ítems)

Módulo opcional. Se activa por campaña mediante `module_instrument_ids`.

---

## CLI — Orientación al Cliente (4 ítems)

> Base teórica: Customer Orientation (Narver & Slater 1990), Service Climate (Schneider 1998)

| #   | Ítem                                                                                                                 | Tipo |
| --- | -------------------------------------------------------------------------------------------------------------------- | ---- |
| 1   | La organización demuestra un enfoque claro y estratégico para mejorar la experiencia de sus clientes.                | (A)  |
| 2   | El compromiso con la resolución efectiva de los problemas de los clientes es claro y compartido por todas las áreas. |      |
| 3   | Las decisiones que toma la organización reflejan una comprensión profunda de las necesidades del cliente.            |      |
| 4   | La organización pone al cliente en el centro de sus estrategias y procesos.                                          |      |
