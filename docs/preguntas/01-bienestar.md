# Bienestar (6 dimensiones, 27 ítems)

Nivel de análisis: **Individual**

---

## 1. ORG — Orgullo Institucional (4 ítems)

> Base teórica: Mael & Ashforth 1992, Psychological Ownership (Pierce 2001)

| #   | Ítem                                                             | Tipo |
| --- | ---------------------------------------------------------------- | ---- |
| 1   | Me siento orgulloso/a de pertenecer a esta organización.         | (A)  |
| 2   | Recomendaría esta organización como un buen lugar para trabajar. |      |
| 3   | Los valores de la organización son compatibles con los míos.     |      |
| 4   | Frecuentemente considero buscar empleo en otra organización.     | (R)  |

---

## 2. PRO — Propósito del Trabajo (5 ítems)

> Base teórica: Meaning of Work (Steger 2012), UWES-9 dedicación

| #   | Ítem                                                                                         | Tipo |
| --- | -------------------------------------------------------------------------------------------- | ---- |
| 5   | Mi trabajo tiene un propósito claro que me motiva.                                           | (A)  |

| 7   | Las tareas que realizo son significativas y relevantes.                                      |      |
