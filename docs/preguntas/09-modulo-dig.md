# Módulo: Preparación Digital — DIG (1 dimensión, 4 ítems)

Módulo opcional. Se activa por campaña mediante `module_instrument_ids`.

---

## DIG — Preparación Digital (4 ítems)

> Base teórica: Technology Acceptance Model (Davis 1989), Digital Readiness (Parasuraman 2000)

| #   | Ítem                                                                                                       | Tipo |
| --- | ---------------------------------------------------------------------------------------------------------- | ---- |
| 1   | Comprendo cómo las nuevas tecnologías pueden mejorar mi trabajo diario en mi área.                         | (A)  |
| 2   | La organización me ha proporcionado información y capacitación sobre el impacto de las nuevas tecnologías. |      |
| 3   | Me siento entusiasmado/a con las herramientas tecnológicas que la organización implementa.                 |      |
| 4   | La organización invierte adecuadamente en tecnología que facilita nuestro trabajo.                         |      |
