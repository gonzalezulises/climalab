## eNPS — Employee Net Promoter Score

> En una escala de 0 a 10, ¿qué tan probable es que recomiendes esta organización como un lugar para trabajar?

| Categoría   | Rango |
| ----------- | ----- |
| Promotores  | 9–10  |
| Pasivos     | 7–8   |
| Detractores | 0–6   |

**eNPS** = % Promotores − % Detractores
